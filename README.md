# 🏥 Golden Hour

> Universal Medical Emergency QR Code System

Scan a QR code → get critical medical info instantly → notify family automatically.
No app needed for first responders. Built for the Golden Hour.

## Structure
- `apps/mobile/` — Flutter patient app (Android)
- `apps/responder-web/` — React emergency web page
- `backend/` — FastAPI backend
- `docs/` — BRD and Project Blueprint
